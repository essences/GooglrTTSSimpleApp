# TC001: APIキー管理機能テスト

## テスト情報
- **テストケースID**: TC001
- **対象PBI**: PBI-002（APIキー管理機能）
- **テストタイプ**: E2Eテスト（手動）
- **優先度**: 高
- **前提条件の複雑さ**: 低

---

## 目的
APIキーの設定・保存・検証・削除機能が正しく動作することを確認する

---

## 前提条件
- [ ] ブラウザ（Chrome/Firefox/Edge）が起動している
- [ ] アプリケーションのURLにアクセスできる
- [ ] 有効なGemini APIキーを用意している
- [ ] localStorageがクリアされている（初期状態）

---
