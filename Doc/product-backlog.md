# プロダクトバックログ - 研修ナレーションスタジオ

## バージョン情報
- 作成日: 2025-11-24
- 対象プロダクト: 研修ナレーションスタジオ（シンプル版）
- プロダクトゴール: ブラウザだけで Gemini TTS を利用し、講師が原稿を入力して即時にナレーション音声を生成・ダウンロードできる個人向けツール

---

## 技術的負債・リスク

### リスク項目
1. **localStorage 容量制限** (約5MB): 音声Blobをlocalstorageに保存できない
   - 対策: 音声はBlob URLのみ保持、セッション終了後は破棄

2. **API レート制限**: Gemini API のレート制限に抵触する可能性
   - 対策: リトライロジック実装、エラーハンドリング強化

3. **長文処理のタイムアウト**: 非同期処理の時間制限
   - 対策: セクション分割を細かくする、タイムアウト時間を適切に設定

4. **ブラウザ互換性**: Safari, Edge での動作確認
   - 対策: Polyfill導入、クロスブラウザテスト

5. **XSS脆弱性**: ユーザー入力の原稿にスクリプトが含まれる可能性
   - 対策: サニタイゼーション処理、CSP設定

## 定義 (Definition of Ready / Done)

### Definition of Ready (DoR)
- [ ] ユーザーストーリーが明確に記述されている
- [ ] 受入基準が具体的に定義されている
- [ ] 見積もり（SP）が完了している
- [ ] 依存関係が明確になっている
- [ ] 技術的な実装方針が決まっている

### Definition of Done (DoD)
- [ ] 受入基準をすべて満たしている
- [ ] コードがブラウザで動作確認済み
- [ ] エラーハンドリングが実装されている
- [ ] 主要ブラウザ（Chrome, Firefox）で動作確認済み
- [ ] コードにコメントが適切に記載されている
- [ ] セキュリティチェック（XSS対策など）が完了している

## 用語集

- **SP (Story Point)**: 相対的な作業量の見積もり単位。フィボナッチ数列を使用（1, 2, 3, 5, 8, 13...）
- **Epic**: 大きな機能単位。複数のPBIで構成される
- **PBI (Product Backlog Item)**: プロダクトバックログ項目。1つの実装可能な単位
- **DoR**: Definition of Ready（着手準備完了の定義）
- **DoD**: Definition of Done（完了の定義）
- **TTS**: Text-to-Speech（テキスト読み上げ）
- **PCM**: Pulse Code Modulation（音声エンコーディング方式）
