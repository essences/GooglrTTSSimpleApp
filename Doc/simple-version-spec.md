# 研修ナレーションスタジオ（シンプル版）仕様書

## 1. コンセプト
- **目的**: ブラウザだけで Gemini TTS を利用し、講師が原稿を入力して即時にナレーション音声を生成・ダウンロードできる個人向けツール。
- **想定利用者**: 単一ユーザー（講師/制作者本人）。ワークスペース共有や権限管理は行わない。
- **運用前提**:
  - API キーやストレージなどの秘匿情報はブラウザに保存する（`localStorage`）。
  - サーバサイド処理・外部 DB・クラウドストレージは使用しない。
  - 音声ファイルは生成直後にブラウザからダウンロードして終了。履歴の永続化は `localStorage` に JSON を格納する簡易版のみ。

## 2. 主要機能
1. **API キー設定**
   - UI 上で Gemini API キーを入力し、`localStorage` に保存/読み出し。
   - 保存済みキーの検証（テストリクエスト）と削除ボタンを提供。
2. **原稿入力（Script Editor）**
   - Markdown 風テキストエリア、Import TXT、Sample Script などの基本操作を提供。
   - 文字数カウントはクライアント側で計算。
3. **スピーカー/生成設定**
   - 話者 2 名までの名前、スタイルメモ、プリセット（固定リスト）を入力。
   - 出力フォーマット（WAV / WAV+MP3）、温度、セクション分割閾値などをフォームで設定。
4. **音声生成フロー**
   - 生成ボタン押下で前処理→Gemini API 呼び出し→音声 Blob 生成→`URL.createObjectURL` で `<audio>` にセット→ダウンロードリンク生成。
   - 長文はブラウザ内でチャンク分割し、順次 API を呼び出す簡易ループ。並列処理やサーバキューは持たない。
5. **セクションプレビュー / 再生成**
   - 生成済みセクションごとに Play / Re-generate / Download ボタンを表示。Regenerate は対象セクションだけ再度 API を叩き、結果を差し替える。
6. **履歴表示**
   - ローカルで生成したジョブを `localStorage` に保存し、簡易テーブルで一覧表示（タイムスタンプ、セクション数、フォーマット、ダウンロードリンク）。
7. **通知/進捗**
   - SSE を使わず、クライアント内で進捗バーを更新（チャンク処理ループの進捗率を計算）。

## 3. アーキテクチャ（シングルページ構成）
- **UI フレームワーク**: Vanilla JS + Web Components もしくは軽量な React/Vue。ビルドレスを重視する場合は CDN 版で完結させる。
- **状態管理**: `localStorage` とインメモリの `appState` オブジェクトのみ。
- **API 通信**: `fetch` で直接 Gemini TTS REST API を呼び出し、レスポンスの音声データ（Base64 / ArrayBuffer）を扱う。
- **ファイル操作**: `Blob`, `URL.createObjectURL`, `<a download>` でダウンロード提供。
- **セキュリティ**: API キーはブラウザ保存になるため、XSS 対策（Content Security Policy、ユーザー入力のサニタイズ）を最低限実装。

## 4. ユースケースフロー
1. ユーザーがアプリを開くと API キー入力モーダルが表示される → キーを保存。
2. Script Editor に原稿を貼り付ける → スピーカー/設定を入力 →「音声を生成」。
3. クライアント内でセクション分割 → 1 セクションずつ Gemini API へ `fetch` → 成功時に音声 Blob を作成し、セクションカードに音声プレーヤーをバインド。
4. 生成完了後、履歴にジョブ情報を保存し、必要ならセクション単位で再生成→ダウンロード。
5. ブラウザを閉じると処理は終了し、履歴は `localStorage` のみ残る。

## 5. 割り切り事項
- マルチユーザー、共同編集、サーバサイド永続化、Observability、SSE 通知、クラウドストレージ連携は対象外。
- 60 分超の長文生成やレート制御はブラウザ内ループで対応できる範囲に限定。タイムアウトした場合はユーザーに再実行を促すのみ。
- エラーロギングはコンソール出力＋画面上の簡単なアラートに留める。
- 認証/認可は実装せず、API キー入力のみで動作する。

## 6. 今後拡張する場合の導線
- ローカル保存をバックアップ/共有できるよう、ブラウザから JSON エクスポート/インポート機能を追加する。
- API キーを UI からサーバにプロキシする構成に切り替えれば、じょじょにサーバサイドアーキテクチャへ移行可能。
- クラウドストレージや履歴 DB、SSE 通知などフル機能が必要になった際は、現行のバックログに沿ったレイヤーアーキテクチャへ段階的に戻す。
